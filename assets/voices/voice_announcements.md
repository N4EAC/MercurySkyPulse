Voice announcements are to be played via the same voice-chat audio output device in specific occasions.
Map the following mp3 audio files as directed:

disconnected.mp3 -> when a connection ends (disconnected by user, lost or timed out) between stations
connected.mp3 -> when a station is connected
calling_cq.mp3 -> when CQ call is sent
transmitting_beacon.mp3 -> when a beacon is sent automatically or manually

Voices should have a setup tab in settings: User may chose to disable / mute voices.
Settings must be remembered.
